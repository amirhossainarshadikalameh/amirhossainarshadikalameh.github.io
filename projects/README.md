# Project pages

One page per research project. The main page's **Research** tab shows a card for each, and *Read more* opens the page here.

| File | What it is |
|---|---|
| `<name>.html` | the project page — question, approach, results, outputs |
| `<name>.svg` | its picture, used both on the card and at the top of the page |
| `project.js` | the light/dark switch for these pages |

**To use a real figure instead of the illustration:** upload your image with the same name (for example `network-complexity.png`), then in both `<name>.html` and the card in `../index.html` change `network-complexity.svg` to `network-complexity.png`. Pictures look best at 16 : 10.

The current pictures are schematic illustrations drawn from synthetic inputs — they show each method or system, not research results — and every caption says so.
